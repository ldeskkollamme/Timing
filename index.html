How To Play

  1. Enter Name & Create / Join: Type nickname, host creates a 6-digit room, friend joins with code or link.
  2. 100 Levels of Escalation:
    • Level 1 has 2 number circles.
    • Level 2 has 3 number circles.
    • ... up to Level 100 with 101 circles!
  3. Each Level has Exactly 2 Turns:
    • Turn 1: Player 1 secretly picks → Player 2 guesses. Correct = P2 +1.
    • Turn 2: Player 2 secretly picks → Player 1 guesses. Correct = P1 +1.
  4. 15-Second Timer: Each pick/guess has 15s. Timeout = auto-pick & 0 pts for missed guess.
  5. Anti-Cheat & Sync: Secret sealed until reveal. Firebase listeners sync both screens instantly.
  6. Victory: After 100 levels (200 turns), highest score wins. Play Again to rematch!
